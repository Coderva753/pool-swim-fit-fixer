# PoolFix

Локальное браузерное приложение для исправления ошибочно разбитых отрезков в тренировках Garmin Pool Swim.

## Запуск готовой версии

Откройте `dist/poolfix.html` двойным щелчком. Устанавливать приложение, сервер или среду выполнения не требуется. FIT-файл обрабатывается только в памяти браузера.

## Использование

1. Перетащите исходный `.fit` в окно.
2. Выберите два или несколько соседних активных отрезков одного интервала.
3. Нажмите «Объединить» и проверьте новую дистанцию.
4. Нажмите «Скачать исправленный FIT».

Исходный файл не перезаписывается. Результат получает суффикс `_fixed.fit` и перед скачиванием проверяется официальным Garmin FIT SDK: заголовок, размер, CRC и агрегаты плавательной сессии.

## Разработка

```text
pnpm install
pnpm build
```

Основная логика находится в `src/fit.ts`, интерфейс — в `src/main.ts` и `src/styles.css`.
